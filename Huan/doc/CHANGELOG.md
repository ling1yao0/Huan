# 更新日志 (Changelog)

本项目所有值得注意的更改都将记录在此文件中。

## [v1.1.2] - 2026-11-13 
### Fixed (修复)
- 解决了发键路径中的 `Sleep` 阻塞，杜绝了按键卡死。
- 解决管理员权限丢失问题，开机自启改用任务计划程序（高权限静默运行）。
- 修复了窗口聚焦失败导致快捷键乱发、甚至发到后台窗口的问题。

### Initial Release (初始版本)
- 第一个正式可用版本。
- 支持基础轮盘呼出、动作页、剪贴板操作等功能。
